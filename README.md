# 研究ログ

## 概要

研究内容と作業時間を記録できる、ブラウザ完結型のWebアプリです。
日々の研究メモ、タグ、進捗率を保存し、累計作業時間や今週の進捗を確認できます。

HTML・CSS・JavaScriptを1つの `index.html` にまとめているため、サーバーを用意せずに利用できます。

## 使い方

### 実行方法

1. このリポジトリをダウンロード、またはクローンします。
2. `index.html` をWebブラウザで開きます。

```bash
git clone git@github.com:tanakalab-sit/2026-ikezawa-codex-sample.git
```

### 操作方法

1. 日付を入力します。
2. 研究内容をメモ欄に入力します。
3. 必要に応じてタグをカンマ区切りで入力します。
   - 例：`実験, 分析, 論文`
4. 作業時間を分単位で入力します。
5. 進捗を0〜100%で入力します。
6. 「追加」ボタンを押すと、記録が一覧に追加されます。
7. 一覧の「削除」ボタンで不要な記録を削除できます。

## 実装した機能

- 日付・研究内容・タグ・作業時間・進捗率の入力
- 研究記録の追加
- 新しい記録を上に表示
- 記録の削除
- `localStorage` によるデータ保存
- ページを再読み込みしても記録を保持
- 累計作業時間の表示
- 記録した日数と記録件数の表示
- 今週の作業時間と300分目標のプログレスバー表示
- タグごとの進捗率表示
- 空欄や不正な作業時間・進捗率の入力チェック
- 壊れた保存データがあってもアプリが停止しないエラー処理
- スマートフォン画面に対応したレスポンシブ表示

## 工夫した点

- **データをブラウザに保存**
  - 外部データベースを使わず、`localStorage` に保存することで、簡単に使い始められるようにしました。

- **入力ミスへの対応**
  - 研究内容の空欄、1分未満の作業時間、0〜100%以外の進捗率を受け付けないようにしています。
  - 保存データの読み込みに失敗しても、空の一覧からアプリを継続できます。

- **進捗を複数の視点で確認**
  - 累計作業時間だけでなく、今週の目標に対する進み具合と、タグごとの進捗率を表示しています。
  - 同じタグの記録が複数ある場合は、最新の記録の進捗率をそのタグの現在値として表示します。

- **安全な一覧表示**
  - 入力したメモやタグを画面に表示する際にHTMLエスケープを行い、入力内容がHTMLとして解釈されないようにしています。

- **1ファイルで完結**
  - HTML、CSS、JavaScriptを分離せず、`index.html` だけで動作する構成にしています。
